Function Transformations

Pick a base function f, then slide it sideways, stretch it up, squash it in and fold it over the axis with four transformations that compose. The faint curve is the original f, the bold one is the transformed g. Drag the amber probe x∗ to read both at one x and to watch where a single point of f lands.

The transformed function \(\displaystyle g(x) = f(x) \) \(\displaystyle (x,\,y)\mapsto(x,\,y) \)

The misconception this kills

"f(x+a) moves the graph to the right by a" is false. Adding inside the bracket moves the graph the other way: g(x) = f(x+a) already has at x the value f used to have at x+a, so every feature arrives a units earlier, to the left. Right now ?.

Mathematics: g is evaluated exactly as the displayed composition, g(x) = A·f(bx+a) or A·f(b(x+a)) with |·| last; the point map is the inverse substitution x′ = (x−a)/b or x/b−a, y′ = Ay.
