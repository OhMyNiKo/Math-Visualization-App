# Physics Intuition App

Twenty-nine interactive modules for building intuition in calculus, linear algebra and physics.
Plain HTML, CSS and JavaScript with no build step.

- `index.html`: launcher page linking every module
- `theme.css`, `theme.js`: shared by every page (`theme.js` also loads KaTeX)
- `vendor/katex/`: local copy of KaTeX

Run locally with `python3 -m http.server 8000` and open http://localhost:8000.
